Reports quoted Iconify icon names whose set exists but the icon doesn't, usually a typo such as "mdi:hoem" or "material-symbols:setings". Libraries such as @iconify/react render nothing for them, without any error.

The quick fixes replace the name with the closest real icons of the same set.

Names are checked against the set's icon list, which is downloaded once from the Iconify API and cached. Strings whose prefix isn't an Iconify set, such as "12:30", are ignored.
